# Pitch video

HyperFrames project: each scene is an HTML page animated with GSAP, rendered locally to MP4. Workflow, layout and rights are in `README.md`; read it first.

## Where things live
- Source of truth for story: `storyboard.md` (scenes, timings) and `script/voiceover.md` (one `## <id>` section per clip; `>` lines are direction notes, not spoken).
- The HyperFrames project is `composition/`. Run all `npm`/`npx hyperframes` commands from there. `composition/CLAUDE.md` holds the framework's own rules (generated by `hyperframes init`); follow it for any scene or `index.html` edit and don't hand-edit it.
- Load the `hyperframes:hyperframes` skill before editing scenes.

## Non-obvious
- `tools/tts.py` needs `ELEVENLABS_API_KEY` in the environment. Never write it to a file. Use `--dry-run` before spending API credits; existing clips are skipped unless `--force`.
- After regenerating voice clips, measure durations with `ffprobe` and update scene timings in `index.html` to match.
- Suno music is downloaded by hand to `composition/assets/music/` (`sad.mp3`, `hopeful.mp3`); there is no API to script.
- Renders go to `out/` (git-ignored). Don't commit MP4s or `composition/node_modules/`.

## Verify
1. `cd composition && npm run check` (lint, layout, motion, contrast)
2. `npx hyperframes render -o ../out/pitch.mp4` for a full render
