# Pitch video

The end-of-day pitch video, built as code with [HyperFrames](https://github.com/heygen-com/hyperframes): each scene is an HTML page animated with GSAP, rendered locally to MP4 with headless Chrome and FFmpeg. Claude Code writes and edits the scenes; ElevenLabs provides the voiceover and Suno the music.

## Layout

```
video/
├── storyboard.md          scene list: timing, visuals, voiceover, audio cues
├── script/voiceover.md    narration, one "## <id>" section per clip
├── tools/tts.py           turns the script into MP3s via ElevenLabs
├── composition/           the HyperFrames project
│   ├── index.html         root composition (1920x1080): places scenes and audio on the timeline
│   ├── compositions/      one HTML file per scene (see storyboard.md for names)
│   ├── assets/voice/      ElevenLabs clips (generated by tools/tts.py)
│   ├── assets/music/      Suno tracks (downloaded by hand)
│   ├── assets/sfx/        sound effects
│   ├── assets/images/     app screenshots, logos
│   └── CLAUDE.md          HyperFrames' own rules for agents (generated by `hyperframes init`)
└── out/                   rendered MP4s (git-ignored; share renders on the team Google Drive)
```

## Requirements

- Git LFS: audio and video files are stored in LFS (see `/.gitattributes`). Install it before cloning or pulling, or you'll get pointer files instead of audio:
  ```bash
  sudo apt install git-lfs && git lfs install
  git lfs pull   # if you already cloned without it
  ```
- Node.js 22+ and FFmpeg (both already on the dev machine).
- The HyperFrames Claude Code plugin, so Claude knows the framework's rules. Each person runs once:
  ```bash
  claude plugin marketplace add heygen-com/hyperframes
  claude plugin install hyperframes@hyperframes
  ```
  Then start Claude Code in `video/composition/` and use `/hyperframes:hyperframes`.

## Workflow

1. **Agree the story.** Edit `storyboard.md` and `script/voiceover.md`.
2. **Voiceover.** Generate clips with ElevenLabs:
   ```bash
   echo 'ELEVENLABS_API_KEY=...' >> .env  # from https://elevenlabs.io/app/settings/api-keys; .env is git-ignored. Or `export` it instead.
   pip install python-dotenv             # lets tts.py read .env (optional if you export the variable)
   python3 video/tools/tts.py --dry-run  # check what will be spoken
   python3 video/tools/tts.py            # writes composition/assets/voice/s1.mp3 …
   python3 video/tools/tts.py s4         # regenerate a single clip
   ```
   Set `ELEVENLABS_VOICE_ID` to change the narrator. Character voices live in `VOICES` in `tools/tts.py` (`irene`, `handler`, `worker`, `agent`); give a clip one with `## s5 voice=irene` in `script/voiceover.md`. Check clip lengths with `ffprobe -i <file> -show_entries format=duration -v quiet` and update scene timings to match.
3. **Music.** Suno has no public API: generate tracks in the Suno web app (for example "sombre lo-fi piano, 30 s" for scenes 01–03 and "uplifting electronic, optimistic, 45 s" from scene 04), download the MP3s and save them as `composition/assets/music/sad.mp3` and `composition/assets/music/hopeful.mp3`.
4. **Build scenes.** Ask Claude Code (with the HyperFrames plugin) to build each scene from the storyboard, e.g. "Using /hyperframes, build scene 03 council-inbox from video/storyboard.md". Audio goes in `index.html` as timed elements:
   ```html
   <audio data-start="0" data-duration="30" data-track-index="2" data-volume="0.4" src="assets/music/sad.mp3"></audio>
   ```
5. **Preview and check.**
   ```bash
   cd video/composition
   npm run dev       # browser preview with live reload
   npm run check     # lint, layout, motion and contrast checks
   ```
6. **Render.**
   ```bash
   npx hyperframes render -o ../out/pitch.mp4
   ```
   Renders stay out of git: upload the MP4 to the team Google Drive and link it from the PR.
